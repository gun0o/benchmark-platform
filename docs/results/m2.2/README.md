# M2.2 verification runs (2026-09-18)

Machine: Intel Core Ultra 9 185H, WSL2 (22 Hyper-V vCPUs), Ubuntu 22.04.5, g++ 13.4.0,
release preset (`-O3 -march=native -fno-omit-frame-pointer`), plugged in. Defaults in
force: `--warmup 5 --warmup-ms 500 --spin-ms 500`. Interpretation is in
`docs/notes/M2.2.md`.

| file | command (from `engine/`) |
|---|---|
| `summary_sweep.json` | `bench run -w cpu_int -t 1,2,4,8 -n 30 --trial-ms 50 --pin` |
| `max_seconds.json` | `bench run -w cpu_int -t 1,2 -n 1000 --trial-ms 50 --max-seconds 3` |

Both files carry a `summary` array with one entry per configuration
(`n, mean, median, stddev, cov, min, p5, p95, max, mad`) alongside the per-trial
`results`. `max_seconds.json` is a deliberately truncated run: it asked for 2000 trials
and the cap stopped it after 50, and its single summary covers exactly those 50.

The statistics fixtures live at `engine/tests/fixtures/stats.json`, regenerated by
`engine/tests/fixtures/gen_stats_fixture.py` (numpy 2.4.6, seed 20260918). The C++
implementation must match them to a relative tolerance of 1e-9.
