# M5.2 — Synthetic data generator

Raw output of the M5.2 verification, 2026-09-21. Reasoning: `docs/notes/M5.2.md`.

`seed.json` is **not** committed: it is 43 MB and regenerates byte-for-byte from
`go run ./cmd/seed --seed 42`.

| file | what it is |
|---|---|
| `seed.log` | the seeding run: row count, time, `--out`, the 100K floor, determinism |
| `spot_checks.log` | all 12 metrics in SQL, the machine inventory, CoV per config, API-vs-SQL filter counts |
| `explain.log` | the query plans over 112,510 rows — the M5.1 verify step, now answerable |
| `tests.log` | `go test ./...`, `go test -tags integration ./...`, and the per-test list |

## Commands

```bash
cd api
go run ./cmd/seed --post http://localhost:8080          # 112,500 rows
go run ./cmd/seed --machines 5 --trials 100 --seed 42 --out seed.json
psql -c 'select count(*) from measurements'
```
